# Air Screenshot 使用指南

本文面向日常使用。程序默认快捷键均可在“设置 → 快捷键”中修改；若快捷键与其他程序冲突，保存设置时会保留原组合并提示重新选择。

## 1. 启动与恢复入口

- 双击 `AirScreenshot.exe` 启动后台服务，默认截图快捷键是 `Ctrl+Alt+A`。
- 托盘图标可以在“设置 → 应用与外观”中隐藏，截图快捷键仍会工作。
- 隐藏托盘后，可运行 `AirScreenshot.exe app tray show` 恢复图标，或运行 `AirScreenshot.exe app settings` 直接打开设置。
- 若需要确认后台服务和快捷键状态，运行 `AirScreenshot.exe app status --json`。

## 2. 选择截图区域

按 `Ctrl+Alt+A` 后：

- 移动鼠标会优先识别当前窗口及更细的可访问控件；滚轮可在候选父子层级间切换。无法使用 UI Automation 时会自动退回稳定的窗口边界识别。
- 拖动空白处创建自由选区；拖动边缘或控制点调整大小。
- 选区内尚无标注时，方向键移动选区 1 px；`Ctrl+方向键` 向按键方向扩大 1 px，`Shift+方向键` 从对应边缩小 1 px。同时按住 `Ctrl+Shift` 不改变选区，避免误操作。
- 调整大小时按住 `Shift` 保持原比例，按住 `Alt` 以中心缩放。
- 选区完成且尚未添加标注时，点击尺寸标签或按 `F2` 打开“精准选区”。可直接输入虚拟桌面 `X / Y / W / H`，负坐标适用于主屏左侧或上方的显示器；可选以中心调整或固定左上角，也可锁定当前宽高比。修改 X/Y 时坐标优先，只改宽高时才按所选锚点调整。
- “精准选区”还可选择直角或圆角输出，并以 px 输入圆角半径。半径会按最终图像尺寸安全限制；取消、非法数值、超出虚拟桌面或不可用的混合 DPI 结果都不会破坏当前选区。
- 选区前按 `C` 复制放大镜中心的颜色值，按 `Shift` 在 HEX 与 RGB 显示间切换。

成功完成一次区域截图后，托盘中的“重复上次区域”或命令 `AirScreenshot.exe capture repeat` 可直接再次截取。多屏顺序、分辨率或坐标变化时，程序会验证当前实际屏幕并调整位置；没有历史、区域已完全离屏或显示器不可用时会给出明确错误。

## 3. 标注与输出

工具栏支持选择、矩形、椭圆、直线、箭头、画笔、文字、序号、马赛克、模糊、高亮、水印、橡皮、撤销与重做。图标按 Stitch 的统一光学网格和线宽重绘，马赛克/模糊、滚动截图/贴图、OCR/复制/保存等相邻动作使用可区分的轮廓，并保留一致的悬停、按下、选中和焦点状态。常用操作：

- `S/R/E/L/A/P/M/B/H/T/N/D` 分别切换选择、矩形、椭圆、直线、箭头、画笔、马赛克、模糊、高亮、文字、序号与橡皮；可在设置中改键。
- 默认 `Shift+C` 对当前选区执行 OCR；这与选区前单独按 `C` 复制放大镜中心颜色是两个不同操作。
- 图形绘制时，`Shift` 约束正方形、正圆或 45° 方向，`Alt` 从中心绘制。
- 切到选择工具后可拖动标注或控制点；`Ctrl+D`、`Ctrl+拖动` 克隆，`Delete` 删除，`Shift+Delete` 清空全部标注。
- 选中标注对象时，方向键移动 1 px，`Shift+方向键` 移动 10 px；没有标注时则使用第 2 节的选区微调规则。
- `Ctrl+Z` 撤销，`Ctrl+Y` 或 `Ctrl+Shift+Z` 重做。
- `Ctrl+C` 复制，`Ctrl+S` 保存；`Enter` 执行设置中的默认输出。
- 圆角输出只影响最终图像，不改变标注坐标，并同样作用于直接创建的贴图。PNG 文件、剪贴板 PNG 与 `CF_DIBV5` 保留透明圆角，旧式剪贴板消费者仍可读取合成到白色背景的不透明兼容格式。
- 序号在每次新截图从 1 开始，三位数以上会自动适配；删除后的编号会保持连续、确定。
- 马赛克与模糊可实时调整强度；水印可设置文字和浓度，并可替换或清除；橡皮按对象的真实视觉范围命中，一次连续擦除只形成一个撤销步骤。
- 保存、复制或 OCR 失败不会关闭选区，可修复问题后原地重试。
- 复制会先完整准备全部新格式；旧剪贴板快照是尽力而为，复杂或延迟渲染内容无法快照时仍可继续正常复制。失败后只有本次对象仍为当前所有者才尝试恢复旧内容，不会覆盖其他应用的新写入。读取旧内容约 5 秒仍未完成时会取消准备、禁止后台晚写并允许立即重试；已经开始提交时才会在后台收尾并暂时阻止重复提交。

工具锁定开启时会连续使用当前标注工具；关闭后，每次完成标注会回到选择工具。各工具最后使用的合法样式会在新截图中恢复，选择旧标注不会覆盖工具默认样式。

## 4. 滚动截图

在已完成的选区上点击“滚动截图”：

- 程序锁定启动时的目标窗口，自动采集并拼接滚动内容。
- `P` 或空格暂停/继续，`Enter` 完成，`Esc` 取消。
- 控制条显示当前拼接宽×高、已接入帧数及“等待滚动 / 匹配成功 / 低置信 / 匹配失败”质量状态；颜色只是辅助，状态同时以文字表达。
- 若切换到其他窗口、目标消失或连续帧匹配不可靠，会安全暂停并说明原因；不会带着错误基线继续拼接。
- 继续前会重新验证原目标窗口、窗口几何、选区尺寸、已拼接尺寸和新基线；无法通过时保持暂停，不破坏已有内容。
- 保存或复制失败时，已经拼接的内容仍会保留，可直接重试。

## 5. 贴图

托盘“贴出剪贴板”支持图像、复制的本地图片文件、颜色文本和普通文本；也可选择“从文件贴图…”或把图片拖到已有贴图上。

- 滚轮、`+`、`-`：缩放；右键菜单可输入 10–1000% 精确比例。
- `Ctrl+滚轮`、`Ctrl++`、`Ctrl+-`：调整透明度；`Ctrl+0` 恢复不透明。
- `R/L`：顺/逆时针旋转；`H/V`：水平/垂直翻转；`G/I`：灰度/反色。
- `S`：平滑与像素缩放；`T`：置顶；`0`：适配工作区；`1`：恢复 100%。
- 双击仅隐藏贴图，`Esc` 或右键菜单“销毁”才会释放贴图。
- 开启鼠标穿透后，可从托盘选择“恢复所有贴图交互”，或运行 `AirScreenshot.exe pin restore`。托盘被隐藏时，程序不会允许进入没有恢复入口的穿透状态。

截图期间，当前可见贴图会临时隐藏，截图结束后恢复；用户原本隐藏的贴图不会被误显示。显示器断开或 DPI 改变时，离屏贴图会自动回到可操作区域。

贴图只会在图像解码与像素存储均有效后创建。对 GDI/截图管线中常见的“所有 alpha 保留字节都为 0”，程序按不透明图像解释；对 PNG 等真实含透明度的来源则原样保留。这避免点击“贴图”后只出现透明空窗口，也不会把正常透明 PNG 强制变为不透明。

## 6. OCR

可先在“设置 → 文本与 OCR”选择极速、高精度或兼容档，但不需要手动预装依赖。框选后点击 OCR，或按默认 `Shift+C`：

1. 程序先检查已安装版本；已通过完整验证时直接离线复用。
2. 依赖缺失时自动开始安全准备，显示检查、清单下载/验证、文件进度、安装和最终校验状态；网络未连接会给出可恢复提示。
3. 按 `Esc` 可取消准备或识别任务；取消不会覆盖已验证安装，之后可原地重试。
4. 普通网络/服务错误可重试；签名、哈希、有效期或防回滚失败是安全阻断，不会通过“继续”跳过。检测到用户目录中的本地安装损坏时，流程会自动将无效版本隔离保留后重新准备；若仍不能恢复，则给出可执行建议，而不是静默删除或继续使用损坏文件。

三档均在本机运行：极速档使用 PP-OCRv5 mobile；高精度档以 PP-OCRv5 server 检测配合 mobile 识别，兼顾复杂背景文字定位与可接受延迟；兼容档使用 PP-OCRv4 mobile。小字会进行有限倍数高质量放大，长图会分块识别并去除重叠结果。

依赖包是原生 Rust worker、ONNX Runtime 和模型文件，不包含 Python、Python 包或 PyInstaller。worker 与托盘主进程隔离，同一档位可温热复用，空闲后自动退出。未安装正式且签名有效的依赖时会明确提示，不会用模拟结果代替真实识别；未嵌入清单公钥的开发构建会直接显示不可用，并在网络请求前拒绝下载。

## 7. 更新与故障恢复

- 自动更新每天最多静默检查一次；也可从托盘随时手动检查。
- 关闭自动更新会取消后台自动任务，并暂停由自动检查暂存版本的启动/退出安装；重新开启后恢复。用户主动检查及其确认的待安装版本不受影响。
- 点击“立即重启并更新”会先持久化手动意图；若更新锁暂时占用或界面正忙，入口会保留，稍后重试或正常退出仍按手动更新处理。
- 新版本必须通过大小、SHA256、Authenticode 和内置发布证书指纹校验后才会暂存。
- 程序目录不可安全写入时不会请求提权或覆盖文件，会提示将 EXE 移到普通可写目录。
- 设置保存采用事务式处理：配置、开机启动项或快捷键切换失败时，窗口和草稿仍保留，旧快捷键会恢复。

## 8. 常用命令

```powershell
.\AirScreenshot.exe capture region
.\AirScreenshot.exe capture repeat
.\AirScreenshot.exe capture repeat --output file --path ".\repeat-shot.png"
.\AirScreenshot.exe capture screen --monitor all --output clipboard
.\AirScreenshot.exe pin clipboard
.\AirScreenshot.exe pin file "D:\Pictures\sample.png"
.\AirScreenshot.exe pin toggle
.\AirScreenshot.exe pin restore
.\AirScreenshot.exe ocr region --copy
.\AirScreenshot.exe app settings
.\AirScreenshot.exe app tray show
.\AirScreenshot.exe app status --json
.\AirScreenshot.exe --help
```
