## 本轮落地概览

- 截图：在 HWND 层级识别之外加入有界、异步 UI Automation 控件识别；新增捕捉指针、`F2` 精确 `X / Y / W / H`、锚点、比例锁定、1 px 键盘调整、直角/圆角输出、重复上次区域和多屏拓扑恢复。
- 长截图：目标窗口锁定、上下方向识别、累积尺寸/帧数/匹配质量状态、暂停/继续/完成/取消、连续低置信安全暂停与严格恢复校验均已接入；成功的滚动截图不再误走贴图分支。
- 标注：对象选择与变换、图形样式、箭头方向、平滑画笔、高亮、文字二次编辑、序号重置、效果预览、工具锁定和逐工具样式记忆均纳入同一撤销模型。
- 工具栏：依据 Stitch 图标表和整体标本统一光学网格、线宽、圆角、40 px 命中目标和状态反馈；马赛克/模糊、滚动/贴图和 OCR/复制/保存不再依赖相似图形区分。
- 贴图：补齐文件/拖放来源、隐藏与销毁、批量恢复、精确缩放、透明度、滤镜、旋转翻转、像素缩放和显示器变化恢复；修复截图 alpha 全零被当成全透明以及初始分层窗口空白的问题，真实透明图仍保留 alpha。
- OCR：参考 Snow Shot 已验证的 `paddle-ocr-rs` 原生推理路线，以 Rust + ONNX Runtime 替换 Python/PyInstaller worker；首次使用自动安全准备本地依赖，以稳定状态和文件/字节进度支持取消、重试、离线复用和隔离修复。识别端保留独立进程、结构化结果协议、长图分块、小字高质量预处理、温热 worker、超时/崩溃回退和完整进程树取消。真实准确率和耗时仍只允许在正式签名 payload 上用固定语料报告。
- 系统集成：设置事务、托盘恢复、运行状态诊断、更新任务来源隔离、非阻塞 helper 激活及事务式 OLE 剪贴板已落地。

本轮没有把参考产品的全部能力机械搬入。需要独立数据格式和恢复模型的贴图历史/分组、多选对齐、可逆裁剪，以及录屏、云翻译和表格/公式识别，仍明确留在后续里程碑。

## 本轮必须达到的标准

### 截图与选区

| 能力 | 参考体验 | Air Screenshot 验收标准 |
| --- | --- | --- |
| 智能窗口/控件识别 | Snipaste、PixPin 可选中 UI 元素并在父子层级间切换 | 同一点优先最深、最小且可见的控件；滚轮可在父子层级切换；跨窗口、空白区域和无标题现代窗口均有确定行为 |
| 精确选区 | Snipaste 的像素级移动/缩放与 PixPin 的精确框选 | 无标注时方向键移动 1 px，`Ctrl+方向` 扩大 1 px，`Shift+方向` 缩小 1 px；标注对象独立保留 1/10 px 微调；拖动时 Shift 保持比例、Alt 以中心缩放 |
| 精准几何 | 直接输入坐标与宽高 | `F2` 或点击尺寸标签打开异步原生弹窗；支持带符号的虚拟桌面 X/Y、W/H、中心/左上锚点和宽高比锁定；坐标显式改动时优先；非法值、取消、越界和混合 DPI 均无破坏性副作用 |
| 直角/圆角输出 | Snipaste 专业版提供圆角截图 | `F2` 精准选区内可选直角/圆角并输入有界 px 半径；最终渲染才施加 alpha 遮罩并覆盖复制、保存、滚动截图与直接贴图；PNG/剪贴板 PNG/CF_DIBV5 保留透明，旧格式合成到白色背景 |
| 重复区域 | 高频截取同一区域无需重新框选 | 成功区域持久化；CLI 与托盘可直接重复；拓扑变化、拔屏、显示器空洞、越界裁剪和无历史均有确定结果 |
| 捕捉指针 | Snipaste 可选择保留光标图案 | 设置中显式开关，区域、活动窗口、单屏和全屏语义一致；长截图不会逐帧重复叠加指针 |
| 多屏与 DPI | 跨屏、负坐标和混合 DPI 可用 | 虚拟桌面负坐标不截断；所有浮层都能回到可操作屏幕；控制柄和命中范围随 DPI 一致 |
| 长截图 | PixPin/Snow Shot 的增量拼接与 ShareX 的帧匹配状态 | 锁定目标窗口；显示累积尺寸、帧数和文字化匹配质量；可识别上下滚动；连续低置信/切换目标会安全暂停，继续前重验目标、几何、选区、拼接尺寸和基线；完成后显式输出而不落入贴图；输出失败保留拼接内容 |

### 工具栏视觉与可用性

Stitch 本轮用于产出 Air Screenshot 自有的工具栏图标表与整体界面标本，不作为运行时依赖。实现仍为原生 Win32/Direct2D，使用 20 × 20 光学网格、24 px 图标框、1.5 px 圆角线性笔画和 40 px 命中目标。验收不只看静态图标，还覆盖悬停、按下、选中、禁用、键盘焦点、高对比度和 100%/150%/200% DPI。图标不使用参考产品的专有素材。

### 标注工具

每个工具都必须同时满足：预览与最终结果一致、光标与命中半径一致、退化手势不污染历史、操作可撤销、进行中的手势在保存/复制/OCR 前被确定提交或取消。

| 工具 | 本轮深化重点 |
| --- | --- |
| 选择 | 对象移动、端点/控制柄缩放、Shift 比例、Alt 中心、克隆、删除、键盘微调、撤销重做 |
| 矩形/椭圆 | 描边宽度、填充/空心、实线/虚线、圆角矩形、边界裁切一致 |
| 直线/箭头 | 端点编辑、反向/双向箭头、箭头尺寸随线宽协调、退化线过滤 |
| 画笔 | 平滑路径、连续书写、预览/落笔一致、长路径性能有界 |
| 高亮 | 透明度和宽度一致，支持自由与直线约束，不把透明度误当颜色 |
| 马赛克/模糊 | 强度为零时不产生假效果；预览、输出、选中和橡皮命中采用同一视觉足迹 |
| 水印 | 自定义文字和浓度；重复应用采用可撤销的替换语义；清除、取消或输入失败不污染其他标注 |
| 文字 | 字体、字号、粗体、斜体、背景、边界和二次编辑一致；输入框不遮挡选区关键内容 |
| 序号 | 每次新截图从 1 开始；三位数以上自适应；删除/撤销不会破坏下一编号的确定性 |
| 橡皮 | 光标明确表示删除范围；只影响真实命中的对象；支持连续擦除且一次手势形成一个历史步骤 |
| 工具锁定 | 工具栏默认可达；开启后连续创建同类标注，关闭后回到选择工具 |

### 贴图

| 能力 | 本轮验收标准 |
| --- | --- |
| 来源 | 支持当前截图、剪贴板图像/图片文件/颜色/文本，以及显式本地图片路径；解码或像素存储无效时不创建空贴图，截图成功与贴图动作显式区分 |
| 透明与首帧 | GDI/截图产生的全零保留 alpha 按不透明处理，混合/非零 alpha 原样保留；默认不透明且可交互的贴图先使用普通绘制路径，只在透明度或穿透确实需要时切换分层窗口 |
| 显示状态 | 隐藏与销毁严格区分；单张和全部显示/隐藏均可恢复；截图期间临时隐藏不改变用户状态 |
| 变换 | 滚轮和 `+`/`-` 缩放，透明度调整与重置，旋转、翻转、平滑/像素缩放切换，菜单反映当前状态 |
| 安全恢复 | 鼠标穿透始终存在托盘或 CLI 恢复路径；无目标的切换命令恢复全部不可交互贴图 |
| 输入 | 文件拖放替换前先验证格式与容量；失败时原图、尺寸和状态保持不变 |
| 批量状态 | 托盘显示可见/隐藏数量，并提供全部显示、隐藏、销毁等明确动作 |
| 图像处理 | 灰度与反色可独立组合，始终从未滤镜原图派生；旋转、翻转或替换后重新派生，关闭效果可像素级恢复 |
| 精确缩放 | 25/50/100/200% 预设与 10–1000% 输入；取消、非法值或资源失败不改变原状态 |

贴图历史、分组、多选对齐、可逆裁剪和贴图上的可选择 OCR 文本属于后续独立里程碑。它们需要持久化格式、崩溃恢复和更完整的交互模型，不与本轮稳定性修复仓促耦合。

### 设置、托盘、更新与输出

| --- | --- |
| 设置提交 | 快捷键占用、启动项写入或配置保存失败时窗口和草稿保持；修复外部条件后可原地重试 |
| 快捷键切换 | 正常编辑和取消不释放旧组合；保存时验证、切换、持久化按顺序执行，失败恢复旧组合并明确显示错误 |
| 瞬态宿主 | 后台服务关闭时由 CLI 打开设置，取消后不得留下无托盘、无快捷键的隐形进程 |
| 隐藏托盘恢复 | `app tray show` 可直接恢复；`app status --json` 报告快捷键可用性和运行期错误；Explorer 暂不可用时有界重试 |
| 自动更新 | 自动与手动任务及待安装来源分离；关闭自动更新会取消自动任务并暂停自动来源的安装，不中断用户手动意图；单实例仲裁先于 helper，短暂锁竞争保留立即更新入口，验签和 helper 握手不阻塞 UI |
| 剪贴板 | PNG、image/png、CF_DIBV5 及兼容格式完整暂存后单次 OLE 提交；旧内容采用 OLE/Win32 尽力快照，快照失败不阻断 forward；仅在本次对象仍为 current 时回滚，绝不覆盖并发新内容；准备超时按代次取消且禁止晚写，提交超时后台收尾并防重入，瞬态进程退出后数据仍可读 |
| 透明输出 | 直角输出保持原有不透明行为；圆角输出的 PNG、image/png 和 CF_DIBV5 保留 alpha，CF_DIB/设备位图等旧消费者获得不透明兼容版；不因兼容格式而破坏现代格式的透明角 |
| 高对比与 DPI | 系统配色方案变化强制重建系统色资源；DPI 变化重载当前三选一应用图标，不回退现有视觉设计 |

### OCR

| 目标 | 验收标准 |
| --- | --- |
| 首次准备 | 点击 OCR 自动检查依赖，缺失时不迫使用户先跳设置；准备状态为稳定枚举，显示阶段、文件和字节进度；可取消、可重试错误与安全阻断明确分类 |
| 离线与自动修复 | 每次使用前完整验证已安装依赖；有效本地版本无网络也可使用；检测到无效用户本地安装时自动移入私有隔离目录保留诊断，然后重新准备；恢复失败给出可执行建议，不删除也不修改只读随包组件 |
| 原生执行链 | OCR payload 只包含原生 Rust worker、ONNX Runtime、VC 运行库和模型，不携带 Python 解释器、Python 包、PyInstaller 或隐式回退链 |
| 模型档位 | 极速档使用 PP-OCRv5 mobile；高精度档使用 PP-OCRv5 server 检测 + mobile 识别，避免全 server 识别的高延迟；兼容档使用 PP-OCRv4 mobile |
| 协议可靠性 | 单次与温热模式共用版本化 JSON 契约和有界帧协议；标准输出只承载协议，诊断只写标准错误；重复、未知、缺失或越界字段均被拒绝 |
| 结果完整性 | 保留文字块、四边形、置信度、识别顺序、耗时和预处理信息；纯文本由结构化结果确定生成 |
| 小字识别 | 小选区使用高质量有限倍数放大，不再使用最近邻缩放 |
| 长图识别 | 超长图分块识别，重叠区域去重并还原全局坐标；内存和输出大小有硬上限 |
| 速度 | 根据硬件在 1–4 个推理线程间选择；三档模型参数显式配置；不在主托盘进程常驻模型 |
| 取消与恢复 | Esc 可终止完整子进程树；取消后不污染剪贴板；失败或取消保留截图选区和标注，可直接重试 |
| 真实性 | 单元测试验证协议、预处理和拼接；真实准确率与冷/热启动耗时必须用安装了正式 OCR payload 的固定语料另行测量，不用模拟数据宣称绝对提升 |

## 专业功能的取舍

本轮已将 Snipaste/PixPin 中与当前架构相容、且能建立明确失败恢复语义的体验纳入产品路径：精确几何输入、1 px 选区缩放、比例锁定、圆角截图、本地 OCR、滚动截图可见质量状态，以及稳定的贴图透明语义。这些都是独立实现的行为对齐，不复制参考产品的代码、图标或其他素材。

二维码/条码识别、保留标注刷新底图、图片分组、标注对象旋转/多选对齐、贴图历史、可逆裁剪、输出边框/阴影和更多箭头类型仍保留在后续里程碑。它们需要新的数据模型、持久化或导出契约，不会仅因参考产品已有就在未完整时标记为已交付。

## 暂不照搬的能力

- 录屏、GIF/WebP 视频导出：属于新的媒体管线，不是截图稳定性增强。
- 云端翻译、表格/公式识别：涉及在线服务、隐私、配额和新的输出协议。
- 屏幕热角：收益有限且容易与 Windows/其他工具冲突。
- 任意命令绑定与按进程忽略：需要单独的权限、校验和冲突模型。
- 网络图片直接下载：默认保持本地优先；网页图片可先复制或保存到本地再贴图。

这些取舍不代表永久排除，而是避免把尚未具备完整失败恢复、配置迁移和自动化测试的功能标为“完成”。
